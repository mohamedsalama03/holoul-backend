## HOLOUL mark

`assets/holoul-mark.png` is the pre-existing user-supplied HOLOUL mark copied from the dashboard's `public/brand/holoul-mark.png` (`D:/customers/holoul frontend/dashboard`). Its pixels are unchanged; a PNG provenance text chunk is added to the documentation copy. The original frontend asset is untouched. It is used only to identify this HOLOUL reference and is not part of Swagger UI's Apache license.

No generated imagery is used. The font stack inherits installed Inter when available, then Segoe UI or Arial; no font assets or third-party font calls are required.
