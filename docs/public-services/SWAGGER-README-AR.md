# HOLOUL — مرجع عقد الربط المحلي

افتح index.html مباشرة في المتصفح. جميع ملفات Swagger مرفقة محليًا؛ لا يحتاج فتح المرجع إلى خادم على 8876 أو اتصال خارجي. المرجع للقراءة والبحث والتنزيل، دون تنفيذ طلبات تحمل حسابات أو أسرار.

الإصدار: 1.4.0-public-services-candidate — 202 عملية / 250 مخططًا.
العقد المطابق هو openapi.json؛ openapi.yaml نسخة مكافئة. راجع CHANGELOG.md وresponse-examples.json وتقرير الاختبارات والتسليم.

## ربط المعرض

GET العام مستقل عن الجلسة ولا يحتاج CSRF bootstrap. استخدم المعرّف العام UUIDv7 أو alias UUIDv4 للمشاريع المستوردة. معرف الصورة العام خاص بنسخة نشر واحدة؛ لا تستخدم معرف الرفع الإداري مكانه. احترم Cache-Control ومنع fallback للمحتوى المسحوب، واختبر حد 60 ثانية عبر المسار الكامل للموقع عند قبول الربط.

## ربط التواصل

ابدأ CSRF صراحة عبر /sanctum/csrf-cookie ثم POST بنفس الأصل إلى /api/v1/public/contact-messages. اطلب الاسم والبريد والهاتف الدولي والرسالة، مع شركة اختيارية. أرسل UUID عشوائيًا في Idempotency-Key واحتفظ به لإعادة المحاولة المطابقة ضمن 72 ساعة. لا تنشئ مفتاحًا جديدًا تلقائيًا لطلب نتيجته مجهولة. 201 يعني حفظ الرسالة والإيصال، وليس تأكيد وصول البريد.

## إدارة المحتوى

اقرأ /api/v1/admin/public-content/capabilities بعد تسجيل دخول الموظف وMFA. الصلاحيات الجديدة لـSuper Admin وAdministrator فقط، دون تغيير سياسة منح الأدوار القائمة. أكّد كلمة المرور حديثًا للنشر والسحب والتنقيح اليدوي.

تسلسل الصورة: إنشاء مسودة، حجز metadata والبصمة مع ETag المشروع، رفع البايتات مع ETag الصورة، انتظار Ready، إعادة جلب ETag المشروع، تحديد الغلاف والصورة المميزة، ثم النشر باعتماد الحقوق ومفتاح إعادة المحاولة. لا تعِد استخدام ETag قديم بعد معالجة الصورة.

مدة الاحتفاظ 180 يومًا معلّقة؛ الحذف/التنقيح الآلي معطل. المستلم info@holoul.ly، والإشعارات المحلية تذهب إلى Mailpit. تفعيل بريد الإنتاج ورابط صفحة الإدارة له بوابات منفصلة.

لم تُعدّل نسختا العقد في Dashboard أو الموقع، ولم يُنفّذ تحويل الواجهات أو نشر الإنتاج. شهادة الأداء على VPS ليست جزءًا من جاهزية هذه الدفعة للربط المحلي.
