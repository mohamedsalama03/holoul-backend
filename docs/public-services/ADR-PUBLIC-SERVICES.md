# ADR — PublicPortfolio and Contact (approved scope)

Owner development approval: 2026-09-29; design: docs/website-readiness/2026-09-28/PUBLIC-SERVICES-PROPOSAL-AR.md at 0f3be1e.

Add PublicPortfolio and Contact as write-owning modules, each depending directly only on Audit and its own external-boundary contracts. Application orchestration supplies a trusted current staff context using Identity's locked authorization action; new domain grants are installed by an Identity catalog migration. No new values enter existing frontend capability projections. External object/mail/processing interfaces are implemented through adapters/application composition, never cross-module writes. PostgreSQL owns command deduplication, publication records, message receipts and durable operations. Redis carries operation IDs only.

Public image IDs belong to immutable publication versions and are distinct from administrative asset IDs. Replacing or withdrawing a publication prevents new origin reads of all its image IDs; republishing cannot revive them. Legacy project UUIDv4 aliases are a documented exception for existing public project links. Originals remain private; processed bytes are served only through the current-publication guard. One aggregate 60-second cache budget applies at integration, not one TTL per hop.

Contact receipt and outbox intent commit atomically. Request-body fingerprints are HMACs; personal content is encrypted at rest and never included in audit/queue payloads. The retry window is [received_at, received_at +72h); an expired key begins a new operation atomically. SMTP ambiguity is recorded without blind resend. Production mail links are disabled until the authenticated dashboard route is accepted. Automatic retention/redaction is disabled; manual authorised redaction preserves the receipt and audit.

New tables, constraints and architecture ownership guards are verified before shared runtime activation. The existing B0 ownership, append-only history, database identity separation and inherited session race guarantees remain mandatory. This ADR is not production certification.

Storage refinement: PublicPortfolio owns a disjoint `portfolio/assets/{uuid7}/` namespace in the existing private, encrypted, versioned object bucket. It accepts no Document ID, source key or external URL. Documents reconciliation only handles `quarantine/{uuid7}` and cannot sweep portfolio assets. No new runtime credential or public bucket is introduced. Each asset variant is create-if-absent and hash/version verified; published image IDs authorize access independently. The local edge has no shared response cache; durable invalidation records explicitly attest origin application only. Any future CDN purge adapter and the website cache path require integration acceptance.
