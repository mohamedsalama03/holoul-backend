# Proposals

Owns proposal revisions, exact prices, relational items/deliverables, contributor
history, internal approvals, issuance, customer decisions, command receipts and
typed private-document references. Reads Intake and Discovery only through their
contracts. The outer Commercial workflow composes request/proposal mutations in
one transaction. No provider I/O occurs in commercial actions.
The B6 accepted-proposal contract locks and revalidates the exact owner acceptance
for conversion and projects immutable accepted commercial terms for authorized
Project readers. Conversion preserves the proposal and decision; rescission is
forbidden once Intake is Converted.

See [B5 implementation](../../../docs/B5-IMPLEMENTATION.md) and
[B6 implementation](../../../docs/B6-IMPLEMENTATION.md).
