# Proposals

Owns proposal revisions, exact prices, relational items/deliverables, contributor
history, internal approvals, issuance, customer decisions, command receipts and
typed private-document references. Reads Intake and Discovery only through their
contracts. The outer Commercial workflow composes request/proposal mutations in
one transaction. No provider I/O occurs in commercial actions.
See [B5 implementation](../../../docs/B5-IMPLEMENTATION.md).
