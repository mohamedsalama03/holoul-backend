# Projects

B6 owns converted projects, immutable accepted-baseline references, internal membership,
phase evidence and customer confirmations, state history, milestones, customer updates,
private document references and command receipts. Application coordinates the outer
transaction; Intake owns the Converted source state and Proposals supplies an exact
accepted-revision read contract. B4 Documents retains storage, inspection and download authority.

See docs/B6-IMPLEMENTATION.md for commands, permissions and lifecycle policy. No AI,
expanded Notifications, Reporting, billing, generic tasks or B7 functionality is implemented.
